# RuMedia

Userscript для модерации релизов в админке RuMedia.

## Установка

1. Установи [Tampermonkey](https://www.tampermonkey.net/).
2. Открой [rumedia-release-info.user.js](https://raw.githubusercontent.com/shalynwork/rumedia/main/userscripts/rumedia-release-info.user.js) и нажми «Установить».

Обновления подтягиваются автоматически: при каждом изменении в скрипте повышается `@version`.
